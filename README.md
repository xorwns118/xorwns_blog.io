# xorwns_blog.io

신입 게임 개발자 포트폴리오를 보여주기 위한 정적 GitHub Pages 블로그입니다.

## 구조

```text
.
├── index.html
├── assets/
│   └── css/
│       └── style.css
├── projects/
│   ├── Swifter_Portfolio.html
│   ├── Diana_Action_Game.html
│   └── MyEngine.html
└── Image/
    ├── Swifter_Portfolio/
    ├── Diana_Action_Game/
    └── MyEngine/
```

## 수정 방법

- 메인 목록의 프로젝트 제목, 설명, 링크는 `index.html`에서 수정합니다.
- 각 상세 페이지 내용은 `projects/프로젝트명.html`에서 수정합니다.
- 프로젝트별 이미지는 `Image/프로젝트명/` 폴더 안에서 관리합니다.
- 상세 HTML 안의 이미지 경로는 `../Image/프로젝트명/파일명` 형태로 맞춥니다.
